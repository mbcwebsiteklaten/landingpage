# 1. PROJECT OVERVIEW

## 1.1 Latar Belakang

Bimbel Klub MBC merupakan lembaga bimbingan belajar yang menyediakan berbagai program pendidikan akademik, keagamaan, serta pengembangan kreativitas dan bakat.

Saat ini informasi program tersedia dalam bentuk poster promosi. Informasi tersebut perlu dikembangkan menjadi website agar calon siswa dan orang tua dapat memperoleh informasi secara lebih lengkap, mudah diakses, dan terstruktur.

Website ini akan menjadi media digital resmi untuk:
- Memperkenalkan profil Bimbel Klub MBC.
- Menampilkan seluruh program bimbingan belajar.
- Memberikan informasi jenjang pendidikan yang tersedia.
- Meningkatkan kepercayaan calon siswa dan orang tua.
- Mempermudah calon siswa melakukan konsultasi dan pendaftaran.

## 1.2 Product Vision

Membangun website bimbingan belajar yang informatif, menarik, mudah digunakan, dan mampu menjadi saluran utama untuk mendapatkan calon siswa baru.

**Brand Tagline:**

"Bersama Kami, Temukan Potensi Kecerdasanmu."

## 1.3 Target Pengguna

1. Orang tua yang mencari tempat bimbingan belajar untuk anak.
2. Siswa TK, SD, SMP, dan SMA/K.
3. Calon peserta program mengaji, tahfidz, dan pengembangan bakat.
4. Masyarakat yang mencari kelas privat maupun klasikal.

# 5. FUNCTIONAL REQUIREMENTS

## 5.1 Header & Navigation

Tujuan:
Mempermudah pengunjung berpindah ke bagian website.

Komponen:
- Logo Klub MBC.
- Menu Beranda.
- Menu Program.
- Menu Tentang Kami.
- Menu Galeri.
- Menu Kontak.
- CTA Daftar Sekarang.

Perilaku:
- Header sticky ketika halaman di-scroll.
- Menu mengarah ke section terkait.
- Tombol Daftar Sekarang membuka WhatsApp.
- Navigasi mobile menggunakan hamburger menu.

## 5.2 Hero Section

Tujuan:
Memberikan kesan pertama yang kuat dan langsung menjelaskan layanan Klub MBC.

Headline:

"Bersama Kami, Temukan Potensi Kecerdasanmu!"

Subheadline:

"Temukan pengalaman belajar yang menyenangkan melalui berbagai program akademik, keagamaan, dan pengembangan bakat bersama Bimbel Klub MBC."

CTA:
- Lihat Program.
- Konsultasi Sekarang.

Visual:
- Foto aktivitas siswa.
- Ilustrasi pendidikan.
- Elemen grafis yang ceria.
- Logo Klub MBC.

## 5.3 Program Overview

Menampilkan sembilan program utama dalam bentuk card/grid.

Setiap program card berisi:
- Gambar atau ilustrasi.
- Nama program.
- Deskripsi singkat.
- Jenjang pendidikan.
- Tombol Lihat Detail.

Ketika tombol Lihat Detail diklik, pengunjung diarahkan ke detail program.

## 5.4 Program Detail

Setiap program memiliki halaman detail atau modal informasi.

Informasi yang ditampilkan:
- Nama program.
- Gambar program.
- Deskripsi.
- Manfaat program.
- Jenjang pendidikan.
- Pilihan metode pembelajaran jika tersedia.
- CTA Konsultasi Program.

Contoh:

**Les Matematika**

Program bimbingan belajar matematika untuk membantu siswa memahami materi sesuai jenjang pendidikannya.

Jenjang tersedia:
TK, SD, SMP, SMA/K.

CTA:
"Konsultasikan Les Matematika"

Pesan WhatsApp otomatis:

"Halo Klub MBC, saya tertarik dengan program Les Matematika. Mohon informasi lebih lanjut."

## 5.5 Learning Methods

Menampilkan dua metode pembelajaran yang tersedia:

### Kelas Privat
Informasi mengenai layanan pembelajaran privat.

### Kelas Klasikal
Informasi mengenai layanan pembelajaran klasikal.

Masing-masing dilengkapi:
- Foto kegiatan.
- Penjelasan singkat.
- CTA konsultasi.

Detail teknis pelaksanaan, lokasi, jumlah siswa, dan jadwal akan dilengkapi berdasarkan informasi lembaga.

Menampilkan keunggulan lembaga berdasarkan informasi yang telah dikonfirmasi.

# 7. UI/UX DESIGN REQUIREMENTS

## 7.1 Design Direction

Konsep desain:

**Modern Playful Education Website**

Karakter:
- Modern.
- Colorful.
- Friendly.
- Professional.
- Clean.
- Responsive.

Website harus memberikan kesan profesional kepada orang tua tetapi tetap menarik bagi siswa.

## 7.2 Color Palette

Warna utama:
- Kuning: #F8D62A
- Merah: #F20D16
- Hijau: #0DBB72
- Pink: #F45BB5
- Biru: #87C5F5
- Ungu: #7020E8
- Oranye: #FF791D
- Hijau muda: #B4F66B

Warna netral:
- Putih: #FFFFFF
- Hitam: #171717
- Abu-abu: #F5F5F5

Warna program mengikuti karakter warna pada poster.

## 7.3 Typography

Rekomendasi:
- Heading: Nunito ExtraBold atau Fredoka.
- Body: Inter atau Nunito Sans.

Ketentuan:
- Heading tegas dan mudah dibaca.
- Body text sederhana.
- Hindari penggunaan terlalu banyak jenis font.
- Pastikan keterbacaan di perangkat mobile.

## 7.4 Responsive Design

Website wajib mendukung:
- Desktop.
- Tablet.
- Smartphone.

Prioritas utama adalah tampilan mobile karena calon pelanggan kemungkinan mengakses website melalui WhatsApp dan media sosial.

# 8. TECHNICAL REQUIREMENTS

## 8.1 Platform

Website berbasis frontend modern dan mudah dikembangkan.

Rekomendasi teknologi:
- Frontend: Next.js.
- Styling: Tailwind CSS.
- Icons: Lucide.
- Animation: Framer Motion (opsional).
- Deployment: Vercel atau server hosting yang tersedia.

Untuk versi awal, website tidak membutuhkan backend kompleks.

## 8.2 Performance

Persyaratan:
- Optimasi gambar.
- Lazy loading untuk gambar di bawah fold.
- Responsive image sizing.
- Minimal penggunaan JavaScript yang tidak diperlukan.
- Optimasi SEO.
- Loading website cepat.

## 8.3 SEO

Setiap halaman wajib memiliki:
- Meta title.
- Meta description.
- Open Graph metadata.
- Heading hierarchy yang benar.
- Alt text gambar.
- Sitemap.
- Robots.txt.

Target kata kunci:
- Bimbel Klaten.
- Bimbingan belajar Klaten.
- Les privat Klaten.
- Les Matematika Klaten.
- Les Calistung Klaten.
- Les Bahasa Klaten.

## 8.4 Analytics

Disarankan menggunakan Google Analytics 4 untuk mengukur:
- Page views.
- Scroll depth.
- Klik CTA WhatsApp.
- Klik program.
- Sumber traffic.
